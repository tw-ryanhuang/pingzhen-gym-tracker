# 平鎮健身房人潮指南

Cloudflare Worker 與 D1 製作的手機人潮報表。

- 台灣時間 06:00–21:55，每五分鐘採樣。
- 保留館方原始人數，不扣除疑似殘留值。
- 半小時熱門時段、連續一小時建議、資料更新狀態。
- 報表免登入，提供最近 56 天 CSV。

## 部署

Cloudflare Workers Builds 已連接此儲存庫，正式分支為 `main`。
推送提交後使用 `npm run deploy` 建置部署；結果請查看 Cloudflare Deployments 或提交檢查。

部署沿用 `wrangler.jsonc` 指定的既有 `pingzhen-gym` D1 資料庫，不建立或清空資料庫。

程式語法檢查：`npm run check`。

## 採樣與資料品質

- 營業採樣：06:00–21:55，每五分鐘。
- 額外觀察：05:50、05:55、22:00、22:05、22:15；標記 observation，不納入推薦。
- 零人先寫入原始紀錄，20 秒後複查，兩次人數與時間存於 detail；不改寫原始人數。複查失敗亦留存。
- 零人紀錄暫不納入熱門時段；複查值只供參考。
- 沒有自動扣除、補零或宣稱已重設。開館前後數字可展開檢視。
- 閉館主畫面顯示已閉館，最近人數與時間仍保留。
- 當日走勢在漏採或待確認處中斷，不補值。
- 頁面可見時，每五分鐘重新讀取；回到頁面若已超過五分鐘也更新。不會透過頁面額外抓取官網。

## 驗證

`npm run check` 檢查語法，`npm test` 驗證觀察時段、零人複查、原始值保留、失敗與重複寫入、圖表及閉館畫面。
部署前自動執行這兩項檢查。既有 samples 資料表無須遷移。


## 兩頁報表與 Web App

- `/`：今日首頁，包含最新人數、建議、採樣狀態與當日走勢。
- `/overview`：全局熱門時段，提供星期切換與歷史統計。
- 支援 Web App manifest、192/512 PNG 圖示、獨立視窗與 iPhone 主畫面圖示。
- Safari 分享 → 加入主畫面；若出現以網頁 App 開啟，請開啟。
- 頁面優先從網路載入。離線／伺服器失敗時僅顯示曾載入的快照，並明確標示載入時間；不保證首次瀏覽後兩頁都有快照。
- CSV 不會快取。離線時不會重新抓館方網站。

## 修改哪個檔案？

| 想修改 | 檔案 |
|---|---|
| 標題、說明文字、卡片排列、今日／全局頁內容 | `src/ui/pages.js` |
| 顏色、字級、間距、手機版面 | `src/ui/styles.js` |
| 動態提示文字、圖表、推薦計算、互動與自動刷新 | `src/ui/client.js` |
| 採樣、官網解析、資料庫查詢與路由 | `src/worker.js` |
| App 名稱、manifest、圖示與離線處理 | `src/pwa.js` |
| Cloudflare Worker 名稱、D1 綁定與 UTC 排程 | `wrangler.jsonc` |

在 GitHub 編輯檔案後提交到 main 就會觸發部署；部署前自動執行語法和功能測試。
修改排程時，需同步檢查 worker.js 的營業／觀察時段，以及 client.js 的時間顯示與應採樣計算。
正式程式以本儲存庫為準；不要再使用早期 worker-5min.txt 覆蓋新版。
